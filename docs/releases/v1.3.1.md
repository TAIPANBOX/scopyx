# scopyx v1.3.1

The broker and both its images are built with Go 1.27.4, which fixes GO-2026-6859 in `net/http`. The v1.3.0 images were built with Go 1.27.3. No route, tool, setting or wire format changes.

Tag: `v1.3.1`. The images are `ghcr.io/taipanbox/scopyx:v1.3.1` and `ghcr.io/taipanbox/scopyx:v1.3.1-chromium`, signed and attested separately. There is no moving tag (no `latest`, no `main`).

## Changed since v1.3.0

- #78, `build: Go 1.27.4 for GO-2026-6859`. The `toolchain` line in `go.mod`, the CI `go-version` and the Go version of the `Dockerfile` move to Go 1.27.4. The same change makes CI take the Google Chrome of the runner image for the browser tests, and moves the temporary directory of three `cmd/scopyx` tests to a short path, because Chrome's singleton socket path had run past the 107-byte limit.
- #79, the test of an invalid `wait_for` selector gets the same 40 second browser budget as its sibling tests.
- #76, the gates no longer end a pipe in a `grep` that exits early (invariant 18).
- #77, the actions in the workflows move to newer pinned commits.

## Upgrade

Pull `ghcr.io/taipanbox/scopyx:v1.3.1` (or `v1.3.1-chromium`) and restart. No configuration changes. To roll back, run v1.3.0 again.
