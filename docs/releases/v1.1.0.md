# Scopyx 1.1.0

This is a minor release, not a patch, because the move to agent-stack-go v2 (below) changes how event stream files are created.

## Upgrade first: the event stream file

Since agent-stack-go v2, a stream file this service creates is mode `0640`, not `0644`: the owning account and its group can read it, and no other account can. A new stream file is created only in a directory this service's account owns. An existing file is opened as it is.

A bus directory that is shared between services and not owned by scopyx's account gets no new stream, unless each file is created beforehand by the uid of the service that writes it. Before you start 1.1.0, check who owns the bus directory and the mode of each stream file in it. stack-single creates its files this way; a deployment that does not must do the same.

## Upgrade: the image

Pull `ghcr.io/taipanbox/scopyx:v1.1.0` and `ghcr.io/taipanbox/scopyx:v1.1.0-chromium` in place of the 1.0.2 tags. The configuration and the journal are the same. The image sizes in the README are the 1.0.1 measurements and were not re-measured for this release.

## Changed since 1.0.1

Twenty commits lie between the 1.0.1 tag and this release. The ones that change anything a person sees:

- **Unreadable robots.txt is logged per destination (#60).** Each fetch that proceeds because a robots.txt could not be read now writes one log line: the origin, the mode and the outcome. The path and the query are never logged. The mode and its default are unchanged, so the decision is unchanged.
- **The image is signed in the legacy format (#63).** The image sign steps add `--new-bundle-format=false --use-signing-config=false`, with a comment above each. Remove both flags when policy-controller reads bundles.
- **The agent-stack-go pin moves to the v2 module path, v2.0.0 (#62).** The shared wire-type import moves to `github.com/TAIPANBOX/agent-stack-go/v2`. This is the change described under Upgrade first.

The rest are dependency bumps, the estate secret-scan workflow (#54), the Go toolchain pin moved to go1.27.2 (#53), the agent-stack-go v1.1.0 to v1.3.0 bumps (#51, #58, #59), the actions bumps (#49, #50, #55), and documentation (#52, #57 and a README correction). The chromium screenshot and `wait_for` implementation (#47) and the agent-stack-go v1.0.1 and v1.0.2 bumps (#46, #48) are in the same range.
