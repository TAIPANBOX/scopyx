# Scopyx 1.2.0

This is a minor release. It adds one optional way for a call to carry its credential, for a deployment that puts the TokenFuse MCP broker in front of scopyx. It is off unless `SCOPYX_ACCEPT_KEY_IN_META=1` is set, and with it unset the door reads the header and nothing else, as in 1.1.1. No frozen name in `compat/1.0.json` moved: `scripts/compat-surface.sh` holds that.

## Upgrade

Nothing breaks, and an existing run needs no edit. Pull `ghcr.io/taipanbox/scopyx:v1.2.0` and `ghcr.io/taipanbox/scopyx:v1.2.0-chromium` in place of the 1.1.1 tags. The configuration and the journal are the same. The image sizes in the README are the 1.0.1 measurements and were not re-measured for this release.

To use the new door, set `SCOPYX_ACCEPT_KEY_IN_META=1` on a scopyx that only the broker can reach, and see "Behind the TokenFuse MCP broker" in the README. Rollback is to unset it, or to run the 1.1.1 image.

## Added

- **The key can come through the broker (#71).** The broker forwards a call with nothing of the caller's, so a plane behind it never sees `X-Scopyx-Key`, and an agent holding the key could go round the broker. With `SCOPYX_ACCEPT_KEY_IN_META=1`, a `tools/call` may carry its credential at `params._meta["scopyx/key"]`. The agent writes the handle `{{secret:scopyx_key}}`, the broker fills in the key from its own vault on the last hop, and the agent never holds it. The key resolves to its agent exactly as the header does, so the broker can label a run from the act rather than from a tool name the agent reported.

## Behaviour with the setting on

- **A header wins** when a call carries both a header and an entry in `_meta`.
- **The entry is removed at the door.** The fetch and the answer never hold the key.
- **`tools/call` always needs a credential.** This includes a `tools/call` with no `id`, which is not read as a notification. `initialize`, `tools/list` and `notifications/initialized` need none, because the broker sends them bare and they fetch nothing.
- **The port belongs on a network only the broker reaches.** To find the credential the door reads the body, up to 1 MiB, from whoever reaches the port.
